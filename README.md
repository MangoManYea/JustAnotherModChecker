
# Just Another Mod Checker(JAMC)

A Free Alternative To Sakuraa's Mod Checker




## Features

- Player List And Selector
- Media Manager
- View Players Mods And Suspicious Properties
- See Players Name, Framerate, Ping, Account Creation Date, Color Code, And Mods
